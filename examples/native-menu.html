Native menu bar

On macOS and Windows Window.this.menu = element shows this <menu> as the system menu bar. Items fire click; shortcuts work; role items (copy, paste, quit...) do the standard thing. On Linux the same markup is drawn as a bar inside the window (try NILE_MENU=inline elsewhere).
