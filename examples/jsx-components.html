Components in JSX

New tags, inputs and widgets from JSX and classes, no framework. Each one is a class extending Element.

1. A custom input tag: <rating-input value="3">

Registered with customElements.define; draws with content(); handles clicks with "on click at span"; reports with a change event.

2. A tag with buttons: <qty-stepper min="0" max="9">

3. A class component used as a JSX tag: <Badge level="warn">

Not registered: a class (or function) used as a JSX tag is instantiated when the vnode is rendered.
