The complete list of what Nile supports today, kept as one dense inventory. The [guide](../guide/README.md) teaches the features; the topic pages in this reference give arguments and limits.

# What's supported today

- **Selectors** (Servo's `selectors` crate): type, `.class`, `#id`, attributes (`[a]`, `[a^=b]`, ...), the
  descendant / `>` / `+` / `~` combinators, `:first-child`, `:last-child`, `:nth-child()`, `:not()`, `:is()`,
  `:root`, `:empty`, and `:hover` / `:active` / `:focus` (driven by pointer and focus events).
  `:link`, `:any-link` and `:visited` work (following an `<a href>` marks it visited for the life of the page, `el.state.visited` sets it). Rules with unsupported selectors (`::first-line`, ...) are dropped.
- **Overflow and scrolling:** `overflow` / `overflow-x` / `overflow-y` (`hidden` clips to the padding box; `auto` and
  `scroll` also scroll with the wheel, with scroll chaining to the page, and draw overlay scrollbars). Hit testing,
  hover and `getBoundingClientRect` follow scrolled content; `scrollTop`/`scrollLeft`/`scrollWidth`/`scrollHeight`,
  `scrollTo`/`scrollBy` and `scroll` events work on elements (see `examples/scrolling.html`). Inputs and textareas
  scroll to keep the caret visible.
- **Properties:** `display` (block, inline, inline-block, flex, inline-flex, grid, inline-grid, none), `box-sizing`, `width/height` + min/max, `margin`, `padding`,
  `border`, `border-radius`, `background(-color)`, `color`, `font-size/weight/family`,
  `line-height`, `text-align`, `white-space` (`nowrap`), `font-style`, `text-decoration` (underline, line-through), `flex`, `flex-direction/wrap/grow/shrink/basis`,
  `justify-content`, `align-items`, `gap`.
- **JavaScript DOM** (QuickJS): `document`, `Element`/`Node`/`Text`, `querySelector(All)`, `matches`, `closest`,
  `classList`, `style`, `dataset`, attributes, `innerHTML`/`textContent`, `createElement`, tree edits,
  `addEventListener` with capture/bubble/once, `on*` properties and attributes, `click`/`mouse*`/`key*`/`focus`
  events, `DOMContentLoaded`/`load`, timers, `requestAnimationFrame`, promises, `<script src>` (see
  `examples/scripting.html`). Layout queries: `getBoundingClientRect`, `offset*`/`client*`, `getComputedStyle`
  (common properties), `innerWidth/Height`, `scrollTo`/`scrollY`/`scrollIntoView` (see `examples/measure.html`).
- **Web platform:** `fetch` (`Headers`, `Request`, `Response`, `AbortController`) and `XMLHttpRequest` load files next
  to the page and `data:` URLs, and http(s) when the `net` feature of `nile-engine` is on (the `nile` binary has it;
  `nile-capi` needs `--features net`); requests run on worker threads, so the page never blocks
  (`examples/fetch.html`). Also `MutationObserver`, `URL`/`URLSearchParams`, `sessionStorage` (in memory) and `localStorage` (saved as JSON in the user's data
  directory, one file per page file; `NILE_STORAGE_DIR` moves it or `off` disables it, `Page::set_storage_file` / `nile_view_set_storage_file` choose a file), `matchMedia`, `ResizeObserver` and `IntersectionObserver` (checked after each layout change or scroll; `rootMargin` is ignored), `window.location` (the page's `file://` URL, read-only; no `history` or navigation), `navigator`, `devicePixelRatio`, `structuredClone`, `atob`/`btoa` and `TextEncoder`/`TextDecoder`.
- **Built-in modules:** `import … from "@nile"` (`"@sciter"` is an alias, so Sciter apps keep working) (`on`/`off`/`once`, `$`/`$$`, `uuid`, `encode`/`decode`, `toBase64`/`fromBase64`, `md5`, `crc32`, `parseValue` (JSON++), `devicePixels`, `onGlobalEvent` as window events) and `"@env"` (`OS`, `PLATFORM`, `DEVICE`, `language`, `country`, `userName`, `machineName`, `domainName`, `arguments`, `launch`, `home`/`homeURL`, `path`/`pathURL`, `drives`, `variable`, `exec`), verified against docs.sciter.com/docs/JS.runtime; `examples/nile-modules.html`. `launch` and `exec` run programs, so don't load untrusted pages into an embedder that doesn't want that.
- **Modules and JSX:** `<script type="module">` and `import` of relative files (`./x.js`, `../y.jsx`). JSX in any
  script compiles like Sciter's: `<h1 id="a">Hi</h1>` becomes `JSX("h1", {id: "a"}, ["Hi"])`, which returns a
  vnode array `[tag, attrs, children]`. `append`/`prepend`/`content` render vnodes (strings, nodes and arrays
  too), `patch(vnode, onlyChildren)` reconciles existing DOM, and function components are called as
  `Component(props, kids, parent)`. Replace `globalThis.JSX` to change what JSX means. See `examples/todo/`.
- **Sciter-style helpers** (checked against docs.sciter.com): `$()`/`$$()` (also `el.$`, `el.$$`),
  `el.on("click.ns ^keydown", [selector], handler)` where `handler(evt, matched)` runs with `this` = the element
  it is attached to, `el.once()`, `el.off(name | ".ns" | handler)`, `el.state` flags (`hover`/`active`/`focus`
  from interaction; `checked`, `disabled`, `readonly`, `expanded`, `collapsed`, `current`, `selected`, `invalid`,
  `busy` are runtime flags matched by the same-named `:pseudo-classes`), `elementIndex`, `nodeIndex`,
  `insertAfter`.
- **Drag and drop:** HTML5 drag and drop of `draggable="true"` elements inside a page (all the events, `DataTransfer`, a drag ghost, cursors, Escape) and files dropped from the desktop as `drop` events with `dataTransfer.files`; no dragging out of the window, no default drag of text, links or images ([guide](../guide/drag-and-drop.md), `examples/drag-drop.html`).
- **Updates:** signed content updates for packed apps: `nile --keygen`, `nile --release folder --key k.key` (archive + signed `update.json`), `application.checkForUpdates()` / `downloadUpdate()` / `restartForUpdate()`, verified against the public key in the app's `nile.json` at every start; the runtime isn't replaced, no delta updates or rollback yet ([guide](../guide/updates.md), `examples/updater`).
- **App lifecycle:** one running instance (`<html app-single-instance>` / `nile.json`: a second launch passes its arguments to the first, `second-instance` event), `application.arguments`, `open-url` / `open-file` events (macOS Apple events; `--protocol`/`--file-type` at pack time declare schemes and file types in the bundle and the Linux entry), `application.registerProtocol()` / `registerFileType()` at run time (Windows, Linux) and `application.loginItem`; no auto-updater, installer or code signing yet ([guide](../guide/app-lifecycle.md), `examples/app-lifecycle.html`).
- **Menu bar:** `Window.this.menu = <menu>` is the real menu bar on macOS and Windows (items, shortcuts, checks, submenus, `role`s) and an in-window bar on Linux, from the same markup (`examples/native-menu.html`, [guide](../guide/controls-and-menus.md)).
- **Dragging files out:** `e.dataTransfer.setFiles([...])` in `dragstart` hands the files to the OS when the drag leaves the window (macOS, Windows; not Linux): drop them on the desktop or in another app ([guide](../guide/drag-and-drop.md), `examples/drag-out.html`).
- **`Intl` and locale formatting:** `Intl.NumberFormat` (currency, percent, compact, significant digits), `DateTimeFormat`, `PluralRules`, `ListFormat`, `RelativeTimeFormat` and `Collator` plus `toLocaleString`/`localeCompare` for about two dozen locales (en incl. UG/KE/NG/ZA/IN/GB, fr, de, es, it, pt, nl, sv, ru, pl, tr, sw, ja, zh, ko, hi), defaulting to the OS language; no ICU, so other languages fall back to English wording, no named time zones; [guide](../guide/internationalization.md). **File helpers** in `@env`: `reveal`, `moveToTrash`, `openWith`; [guide](../guide/desktop-helpers.md).
- **Camera and microphone:** the optional `@media` native extension (`extensions/media`: `nokhwa`, `cpal`, `jpeg-encoder`) gives `devices()`, `camera()` (live `ImageData` preview or `drawTo(canvas)`, full-size JPEG `photo()`) and `microphone()` (Int16 mono chunks, level, WAV recording); builds on macOS and type-checks for Windows, checked on a MacBook (camera preview and photo, microphone samples) but not on Windows or Linux; `nile --pack --camera/--microphone` write the macOS usage strings; [guide](../guide/camera-and-microphone.md), `examples/media/`.
- **Serial ports:** `@nile/serial` lists and opens COM/USB-serial/Bluetooth-serial ports (baud, data/stop bits, parity, flow control; `write`, `onData`, buffered `read`/`readUntil` with timeouts, DTR/RTS/break, unplug notice), in the binary (feature `serial`); checked against macOS device nodes and, on Linux CI, a pty pair, not real hardware or Windows; no USB/HID; [guide](../guide/serial.md), `examples/serial.html`.
- **Email:** `@nile/mail` sends through an SMTP server (STARTTLS or TLS, AUTH PLAIN/LOGIN, HTML + text, attachments, inline images, UTF-8 headers) and `buildMessage` gives the raw message; tested against a scripted server, not a real provider, no OAuth2/DKIM/IMAP; [guide](../guide/email.md), `examples/mail.html`.
- **Credential store:** `@nile/keychain` keeps secrets in the macOS Keychain, Windows Credential Manager or the Linux Secret Service (`set`/`get`/`remove`, text or bytes, Promises; cargo feature `keychain`, on by default in nile-engine); only the macOS store has been exercised; [guide](../guide/credentials.md).
- **Crypto:** the standard `crypto.getRandomValues`/`randomUUID`/`crypto.subtle` (SHA-1/256/384/512 digests, HMAC, PBKDF2, AES-GCM with raw keys; heavy work on a worker thread) over `ring`, and `@nile/crypto` with `hashPassword`/`verifyPassword` (PBKDF2-SHA256, 600,000 iterations), `sha256`, `hmac`, `encryptText`/`decryptText`. No RSA/ECDSA, JWK, Argon2/bcrypt or keychain yet; [guide](../guide/hashing-and-encryption.md).
- **Printing:** `Window.this.print({ printer, copies })` / `exportPdf(path)` send the page as paper (`@page`, page breaks, repeated headers) to the system printer or a file; `@nile/print` lists printers and sends files or raw bytes (CUPS on macOS/Linux, PowerShell and winspool on Windows, or a network port); `@nile/escpos` builds receipts for thermal printers (text, rows, barcodes, QR, logos, cut, cash drawer). No print dialog, no direct USB/serial access yet; checked with fake `lp` commands and sockets, not real printers; [guide](../guide/printing.md), `examples/printing.html`.
- **`@nile/ui`:** an optional, built-in component library written in JS (nothing to install, costs nothing unless imported): `<nile-drawer>` (slide-in panel from any edge), `<nile-splitter>` (resizable, collapsible panes with a three-dot grip), `<nile-grid>` (virtual data grid: 100,000 rows, sorting, selection, keyboard, column resize) barcodes/QR codes (`<nile-barcode type="code128|code39|ean13|ean8|upca|qr">`, checked against reference encoders), promise dialogs (`confirm`/`prompt`/`alert`/`dialog`, `<nile-dialog>`), `toast`, `shortcuts` (global keys and `data-shortcut` buttons), `<nile-tabs>`, `<nile-accordion>`, `<nile-combobox>` (filtering, groups, async `source`), a restylable Microsoft-style `ribbon(config)`, `<nile-tiles>` (F-key pads), `<nile-chart>` (bar, line, area, pie, donut), `<nile-tree>` (lazy, filterable), `<nile-keypad>` (till and PIN pads), `<nile-calendar>`/`<nile-date>`/`<nile-date-range>` (pickers with presets), popup and context `menu()`, a `palette` (Ctrl+K command palette and picker) and `<nile-wizard>`; [guide](../guide/ui-components.md), `examples/drawer.html`, `splitter.html`, `data-grid.html`, `barcodes.html`, `ui-dialogs.html`, `ui-navigation.html`, `ui-combobox.html`, `ui-ribbon.html`, `ui-charts.html`, `ui-tree.html`, `ui-inputs.html`, `ui-commands.html`, `ui-wizard.html`.
- **Progress:** `application.progress = 0.4` / `"indeterminate"` / `null` draws a progress bar on the dock icon (macOS) or taskbar button (Windows); none on Linux ([guide](../guide/tray-and-badge.md)).
- **Tray and badge:** `Window.this.tray = {icon, tooltip, menu, template}` (menu-bar item on macOS, notification-area icon on Windows; `trayclick`/`traydoubleclick`, a `<menu>`) and `application.badge` (dock label on macOS, taskbar overlay on Windows); none on Linux yet; the Windows side is untested ([guide](../guide/tray-and-badge.md), `examples/tray.html`).
- **Clipboard:** Sciter's `Clipboard` (`read`, `write`, `readText`, `writeText`, `has`) with text, HTML, images (as `ImageData`), file lists and in-app JSON; the OS clipboard in the `nile` binary; no `link`, one primary flavour per write ([guide](../guide/clipboard.md), `examples/clipboard.html`).
- **Audio:** Sciter's `Audio` class (`Audio.load`, `play()` settling at the end, `pause`/`resume`/`stop`, `volume`, `progress`) and the web `<audio>` / `new Audio(url)` (`play`, `pause`, `currentTime`, `duration`, `volume`, `muted`, `loop`, `playbackRate`, `autoplay`, media events) over the system output device; MP3, WAV and FLAC by default, Ogg Vorbis and AAC behind `audio-vorbis`/`audio-aac`; no Web Audio graph, recording, `controls` UI or network streaming ([guide](../guide/audio.md), `examples/audio.html`).
- **`<canvas>`:** the Canvas 2D context over a Skia surface (paths, `Path2D`, gradients, patterns, shadows, text, `drawImage`, `getImageData`/`putImageData`, `toDataURL`, compositing, `OffscreenCanvas`), `new Image()` and `<img>` `onload`; no WebGL or `ImageBitmap` ([guide](../guide/canvas.md), `examples/canvas.html`).
- **SVG:** inline `<svg>` (sized by attributes or `viewBox`, `currentColor`, page CSS reaching its elements, script-built with `createElementNS`), `<img src=*.svg>` and `background-image: url(*.svg)`, rasterised by resvg at the drawn size ([guide](../guide/svg.md), `examples/svg.html`); no raster `<image>` inside, SMIL or `foreignObject`.
- **Form controls:** `<input>` (text, password, placeholder, `value`), `<textarea>` (wrapping, newlines, Up/Down
  by line), checkboxes and radio groups (including `<label>` clicks), `<button>`, disabled states, a blinking
  caret with click-to-place that scrolls into view, typing, Backspace/Delete/arrows/Home/End, Tab and Shift+Tab
  focus order (`tabindex` respected), and `input`/`change`/`focus`/`blur` events. Undo/redo (Ctrl/Cmd+Z, Shift+Ctrl/Cmd+Z, Ctrl+Y; typing and Backspace runs group into one step), word-wise
  movement and deletion (Alt or Ctrl+arrows/Backspace/Delete, Cmd+arrows/Backspace on macOS), and keyboard scrolling
  outside text inputs (arrows, Page Up/Down, Space, Home/End on the focused or hovered scroller, then the page).
  **Window** (`examples/window.html`): the root `<html>` element configures the native window as in Sciter
  (docs.sciter.com/docs/HTML/html-window): `window-title`, `window-width`/`-height` (px or % of the desktop),
  `window-min-*`/`-max-*`, `window-resizable` (`true`, `false` or an edge margin like `6px`),
  `window-minimizable`/`-maximizable`, `window-state` (`shown`, `minimized`, `maximized`, `full-screen`, `hidden`),
  `window-alignment` (1-9 on the numeric keypad's layout, 5 = centre), `window-icon`, `window-remember` (Nile: reopen with the last size, position and maximized state, kept per app in the user data folder; a position on a monitor that is gone is ignored), and `window-frame`
  (`default`/`standard`, `extended` (macOS: content under the title bar), `solid` (no system frame), `solid-with-shadow` (no frame, the system's drop shadow on macOS and Windows; `examples/solid-shadow.html`),
  `transparent`), and Nile's `window-material` (`blur`, `acrylic`, `mica`, `tabbed`, `sidebar`, `hud`: the system's frosted backdrop behind a page with a transparent background; `examples/transparent.html`, `examples/material.html`). With no system frame, elements with `role="window-caption"` drag the window (double-click
  maximizes) and `role="window-minimize"`/`window-maximize`/`window-close` are the buttons; the edges resize it.
  Scripts get `document.title` (set and get), `window.close()`, `moveTo/moveBy/resizeTo/resizeBy`,
  `screenX/Y`, `outerWidth/Height` and `element.requestFullscreen()`/`document.exitFullscreen()`.
  **Rich-text editing** (`examples/editor.html`, and `examples/word-ribbon.html`, a working word processor): any element with `contenteditable` is an editor. Click, drag, double- and triple-click to select; type; Enter splits paragraphs and list items (Shift+Enter inserts `<br>`); Backspace/Delete (with Alt for words); arrows, Home/End, Cmd/Ctrl+arrows (Cmd = line edges on a Mac, Ctrl = words), with Shift to extend; Cmd/Ctrl+A/Z/Y/B/I/U/C/X/V. `document.execCommand` runs `bold`, `italic`, `underline`, `strikeThrough`, `subscript`, `superscript`, `foreColor`, `backColor`/`hiliteColor`, `fontName`, `fontSize`, `removeFormat`, `justify*`, `insertUnorderedList`/`insertOrderedList`, `indent`/`outdent`, `formatBlock`, `insertText`, `insertParagraph`, `insertLineBreak`, `insertHTML`, `insertImage`, `insertHorizontalRule`, `createLink`/`unlink`, `delete`, `selectAll`, `undo`/`redo`, `copy`/`cut`/`paste`; `queryCommandState`/`Value`/`Enabled`/`Supported` drive toolbars. Nile adds `fontSizePx` and `blockStyle` (`"prop: value; ..."` on the selected blocks). With a caret, a format command applies to the next typed text. `window.getSelection()` has `anchorNode`/`focusNode`/offsets, `getRangeAt`, `addRange`, `collapse`, `extend`, `setBaseAndExtent`, `selectAllChildren`, `toString`; `document.createRange()` gives a `Range` (`setStart`/`setEnd`, `selectNodeContents`, `toString`, `deleteContents`, `insertNode`). Editors fire `beforeinput` (cancelable), `input` and `selectionchange`. A `mousedown` handler that calls `preventDefault()` keeps focus and selection where they are, so toolbar buttons don't steal the caret.
  Page text selection (off by default, like a desktop UI: opt in with `user-select: text`/`all`, a `selectable` attribute, or Sciter's `behavior: htmlarea`; `text-selection-background-color` sets the highlight): drag, double-click (word), triple-click (run), Shift+click, Ctrl/Cmd+A and Ctrl/Cmd+C, with `window.getSelection().toString()`. Text selection in inputs and
  textareas: Shift+arrows/Home/End, drag, Shift+click, double-click (word), triple-click (all), Ctrl/Cmd+A, and
  copy/cut/paste through the system clipboard; Tab selects an input's contents. In JS: `selectionStart`,
  `selectionEnd`, `setSelectionRange()`, `select()`. `<select>` with `<option>`s: a drop-down that opens on click,
  Space/Enter or Alt+Down, with mouse hover, arrows/Home/End, type-ahead, Escape, disabled options, and `input`/
  `change` events; sized to its longest option; a long list scrolls (wheel, arrows) and opens upward when there is
  more room above. `<optgroup label>` headings (bold, unselectable, options indented; `examples/optgroup.html`) work in drop-downs and list boxes. `<select multiple>` and `size > 1` are list boxes drawn inline: click, drag to select a range, Cmd/Ctrl-click to toggle,
  Shift-click to extend, arrows/Page/Home/End (Shift extends), Cmd/Ctrl+A, type-ahead, wheel (see
  `examples/listbox.html`). In JS: `value`, `selectedIndex`, `selectedOptions`, `options`, `option.selected`/
  `text`/`label`/`value`, `length`. In JS: `value`, `checked`, `disabled`, `type`, `name`,
  `placeholder`, `focus()`, `blur()`, `document.activeElement` (see `examples/forms.html`).
- **Pointer interaction:** hit testing (down to the inline element under the pointer), `:hover`, `:active` and
  click-to-focus on links and form controls, restyled live (see `examples/interact.html`).
- **Inline content:** mixed text, `<br>`, inline padding/border/background/radius and `inline-block` (with
  baseline) wrap as one flow (see `examples/inline.html`, `examples/selectors.html`).
- **Modern CSS** (`examples/css-flow.html`, `css-text.html`, `css-effects.html`, `css-logical.html`, `css-counters.html`, `css-modern.html`, `css-scroll-snap.html`):
  `visibility`, `pointer-events`, `outline`(+`-offset`), `order`, `flex-flow`, `aspect-ratio`; `text-indent`, `word-spacing`,
  `word-break`, `overflow-wrap`, `text-shadow`, `text-decoration-style/-color/-thickness`, `text-underline-offset`, `-webkit-line-clamp`,
  `text-wrap: balance`, `caret-color`, `font-variant*`; `filter` (blur, drop-shadow and the colour functions), `backdrop-filter`,
  `mix-blend-mode`, `isolation`, `clip-path` (`circle`, `ellipse`, `inset`, `polygon`), `mask-image` with gradients, `object-fit`/`object-position`;
  logical properties (`margin-inline`, `padding-block`, `inset-inline`, `inline-size`, ... for left-to-right text); CSS counters (`counter-reset`,
  `counter-increment`, `counter()`/`counters()`); `color-mix()`, `oklab()`/`oklch()`/`lab()`/`lch()`/`hwb()`, `color()`, `light-dark()`;
  `abs()`/`sign()`/`sqrt()`/`pow()`/`hypot()`/`log()`/`exp()`/trigonometry/`round()`/`mod()`/`rem()` in `calc()`, `dvh`/`svh`/`lvh`,
  `ch`/`ex`/`lh` (approximate), `env()`; CSS nesting (`&`) and `@layer`; `scroll-snap-type`/`-align` and `scroll-padding` (the container settles
  once the wheel pauses). Horizontal `margin` on inline elements takes space.
- **Not supported yet (modern CSS), and mostly not planned:** Nile is a desktop UI engine, not a browser, so a CSS feature is added only for a named desktop use case (or an example app that can't be built without it), not for parity. Missing: `@container` and `cq*` units, multi-column layout (`columns`, `column-count`), `@property`, `writing-mode`/`direction` (logical properties assume left-to-right), `clip-path: path()` and `inset(... round ...)`, `min()`/`max()`/`clamp()` mixing `%` and `px`, `mask-image: url()` and `mask-size/position/repeat`, `background-clip: text`, `background-origin`, multiple background layers, relative colour syntax, animation of `filter`/`backdrop-filter`, `tab-size`, `hyphens`, `text-align-last`, `scroll-behavior`, `scroll-snap-stop`, `resize`, `border-image`, `content-visibility`, `anchor-name` and `view-transition-*`;
  `will-change` and `contain` are accepted and ignored.
- **Cascade and values:** `!important`, custom properties with `var(--x, fallback)` (inherited, can reference each
  other), `@media` (width/height features incl. range syntax, `orientation`, `screen`, `and`/`not`/commas; re-evaluated
  when the window resizes). `calc()` (including `100% - 20px`, resolved in layout), `min()`, `max()`, `clamp()` (not mixing `%` and `px`).
  **Units:** `px`, `em`, `rem`, `%`, `pt`, `vw`, `vh`, `vmin`, `vmax`, `cm`, `mm`, `in`, `pc`. **Colors:** hex (3/4/6/8
  digits), `rgb()/rgba()` (legacy and `r g b / a` syntax), `hsl()/hsla()`, all CSS named colors, `transparent`,
  `currentColor` (borders follow `color` by default). Borders: per-side width, color and style (`solid`, `dashed`, `dotted`) with mitred corners.
  `text-transform`, `letter-spacing`, `box-shadow` (several, blurred, spread, `inset`; `examples/inset-shadow.html`) and painted `opacity` (a layer
  over the whole subtree) and `position: relative|absolute` (against the nearest positioned ancestor), `fixed` and `sticky` (`examples/fixed.html`) with `top/right/bottom/left/inset` and `z-index` (see
  `examples/position.html`) `linear-gradient`/`radial-gradient` and their `repeating-` forms as `background`
  (`examples/gradients.html`), `transition` (any animatable property or `all`, with delay, `ease`/`linear`/`cubic-bezier()`/`steps()`; a change mid-transition continues from where it is) and `@keyframes` `animation` (with `transitionend`, `animationstart` and `animationend` events carrying `propertyName`/`animationName`/`elapsedTime`; `examples/anim-events.html`; no `transitioncancel`/`animationiteration`) (iterations, `infinite`, direction, fill modes, delays; `examples/animations.html`) over opacity, colors, lengths, padding/border widths, radius, `transform` and more, `transform` (`translate`, `scale`, `rotate`, `skew`, `matrix`, with `transform-origin`; hit testing and `getBoundingClientRect` follow it; `examples/transforms.html`), `<img>` (PNG/JPEG/WebP/GIF from files next to the page or `data:` URLs; sized by CSS, `width`/`height` attributes or the picture) and `background-image: url()` with `background-size`/`-position`/`-repeat` (`examples/images.html`), `float`/`clear` (`examples/float.html`), `<include src media>` (fragments spliced in while loading, with fallback content; `src`, `loadFile`/`loadHtml`/`loadEmpty`, `frame.document.$()`, `newdocument`/`complete`, `postMessage` both ways with `window.parent`; `content-style`; `examples/frames.html`), accessibility for screen readers (UI Automation, VoiceOver, AT-SPI through AccessKit; roles, names, states and actions from the DOM and ARIA attributes; also as JSON from the C API; see `docs/guide/accessibility.md`), `new Window({...})` and `Window.this.modal({...})` (several native windows, each its own page;
