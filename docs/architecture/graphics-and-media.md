# Canvas, SVG and audio

[Architecture index](README.md)

Implementation notes for people changing Nile: `<canvas>`, SVG rendering and `<audio>`. Each note says where the code is and which trap it avoids. They are kept as written while the code was built, so check a name against the source before relying on it.

- `<canvas>` (`nile-canvas`): `canvas.js` (spliced into `web.js`'s block at `/*@CANVAS@*/`) makes `getContext('2d')` create a surface (`N.canvasCreate`) and store its id in the internal `nile-canvas` attribute; every context method is one `N.canvasCall(id, op, numbers, text)` into `nile_canvas::call` (a big `match` on the operation name; errors come back as "\u{1}Name: message" and are thrown by `cvRun`). The JS context mirrors the property values it accepted (the native side ignores invalid ones) and its own save/restore stack. Layout treats `<canvas>` like `<img>` (`build_image`: `width`/`height` attributes, 300x150 default) with an `ImageData { canvas: Some(id), bytes: [] }`; the renderer's `picture()` takes `nile_canvas::snapshot(id)` instead of its cache. Drawing sets a thread-local dirty flag (`take_dirty`) that `Page::sync` ORs into its "repaint" result, so animation never relayouts. The current path keeps device-space points (transformed when added); `Path2D` ids live in a native table and are drawn with the current transform. `drawImage` of an `<img>` gets bytes through `Environment::image_bytes` (the engine's `FileImages`); a canvas source is resolved before the destination is borrowed. Skia 0.93's `Path` is immutable: build with `PathBuilder`.
- SVG (`nile-svg`, `nile-layout/src/svg.rs`): three entry points share `ImageData { svg: Some(SvgInfo { css, stretch }), bytes: <document> }`. Files/`data:` URLs: `FileImages::load` sniffs `looks_like_svg` and takes the size from `nile_svg::size`. Inline `<svg>`: `build_image` calls `inline_svg`, which writes the subtree back out (`svg::serialize`: restores camel-case tag/attribute names the lower-casing DOM lost, adds `xmlns`, the CSS `color` as a `color` attribute for `currentColor`, and a `data-nile-svg=<node id>` marker on every element), uses the viewBox for the natural size, and hashes source+css into `ImageData::id` (high bit set). `svg::page_rules` makes the page's `<style>` rules reach the elements: each selector is matched against the *real* DOM with `nile_style::Query` and re-emitted as `[data-nile-svg="id"] { decls }` for usvg (no specificity between page rules, no at-rules, no `var()`). The renderer's `picture(data, want_size, scale)` rasterises an SVG at `want * device_scale(canvas)` pixels (cache `svg_pictures` keyed by id and pixel size, cleared at 64 entries; background tiles rasterise at the tile size and the shader scales by the bitmap's own size). Children of an `<svg>` are never boxes. System fonts load once per thread, only for documents containing `<text`.
- Audio: `audio.js` (spliced into `web.js` at `/*@AUDIO@*/`) gives `<audio>` elements a hidden controller (`auCtl`) behind `Element.prototype` accessors/methods that only act on `AUDIO` tags; natives `audioLoad(src)` (bytes through `Environment::image_bytes`) and `audioOp(op, id, arg)` call `nile-audio`; `ScriptHost::tick` polls `nile_audio::poll()`/`take_events()` and calls `__audioTick(endedIds)`, ticking every 100 ms while anything plays. `Audio.load()` elements are `sciter` (their `play()` promise settles at the end), `new Audio()`/`<audio>` use web semantics. Position is `base + elapsed * rate` (own clock, not the device's); ended comes from `Player::empty()`. Feature `audio` (default) on nile-engine/nile-script; `audio-vorbis`/`audio-aac` add decoders; Linux needs `libasound2-dev`.
